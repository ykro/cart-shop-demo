# Issue body template (GitHub Markdown)

Render the `body` argument of `create_github_issue` from this template. Keep the headings.

```
## Summary
<one or two sentences: what is wrong and where>

## Steps to reproduce
1. <step with concrete values>
2. <step>
3. <step>

## Expected
<what should happen, with the exact number>

## Actual
<what happens, with the exact number>

## Environment
- Device: <model> (<manufacturer>), Android <version> (API <level>)
- App: Cart Shop <version> (<build type>)
- Coupon: <code and rule, if any>

## Evidence
- Screenshot artifact: <name>
- Breadcrumbs: <comma-separated raw breadcrumbs>
- Last network call: <method url → status>

## Hypothesis
<one sentence, or "None yet">

_Filed by the in-app bug reporter (ADK for Kotlin)._
```
